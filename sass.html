Om att använda SASS

Fördelar

Nesting

Det blir lättare att hålla samma element inom samma sfär: med detta menar jag att exempelvis li element som tillhör navigering går att hitta tillsammans med navigeringen.

Jag ser också att det går att "banta ner" koden något. Istället för att skriva rader med nav, nav ul, nav ul li och så vidare så går det istället att bygga på samma struktur. Ungefär som att lägga till legobitar för att bygga ett torn.

Partials

Betydligt bekvämare och mindre press att felsöka och koda vidare! Du möts inte av en vägg av kod som du måste vada igenom.

Nackdelar

Nesting

Samtidigt som det är lättare att samla de element som hör ihop med varandra, så är det också enkelt att missförstå var man befinner sig, åtminstone i början. Personligen upplevde jag att jag inte visste var jag skulle placera element om jag ville exempelvis använda hover: hur kunde jag "nesta" det utan större problem?

Partials

Det är lätt att, om man inte är försiktig, att skapa väldigt många partials. Och när något sedan inte fungerar kan det bli lite knepigt att lista ut vilken partial som var problemet.

(Jag upptäckte detta genom att ha desktop navigering css i huvud scss filen. breakpoints var en partial. För att göra hamburgermeny arbetade jag i min partial, men upptäckte senare att ingenting fungerade. Visade sig att detta sätt gjorde att hamburgermenyn blev för evigt dold. Gick att lösa genom att flytta all navigation till en egen partial och ta bort breakpoints partial istället)
